Voxel Playground

← compare: sprite stacking version

The same world and the same models as the sprite stacking page, but every filled cell is a real cube. Each model is meshed once into triangles (only the exposed faces) and drawn with WebGL, a depth buffer and per-face lighting — at the same low resolution, so the pixels stay chunky.
